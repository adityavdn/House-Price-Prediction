# 🏡 House Price Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Real Estate](https://img.shields.io/badge/Real_Estate-Regression-orange.svg)

## 📖 Overview

Regression model to predict residential property prices based on features like location, size, bedrooms, amenities, and age. Provides accurate price estimates for real estate valuation.

## 🎯 Features

- Property price prediction
- Feature importance analysis
- Location-based pricing
- Market value estimation

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Quick Start

```bash
git clone https://github.com/adityavdn/House-Price-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Key Features

- Square Footage, Bedrooms
- Location, Neighborhood
- Age, Condition
- Amenities, Parking
